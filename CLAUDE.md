# Max Allison Portfolio

Personal site for Max Allison (software engineer + musician/artist), styled as a
Windows-9x desktop: silver windows on a teal desktop, built on **98.css**, with a
working Winamp-style music player ("MY MUSIC"). Traditional scrolling page, not a
free-form desktop; windows sit at default positions but can be dragged.

## Stack

- Next.js 16 (App Router, Turbopack), TypeScript, Tailwind v4
- **98.css** for all Win98 chrome (windows, title bars, buttons, inputs, scrollbars,
  the pixelated MS Sans Serif font). Imported in `app/layout.tsx` BEFORE
  `globals.css` (bare CSS package imports don't resolve from `globals.css`).
- VT323 (`next/font/google`) only for LCD readouts (`font-pixel`)
- `motion/react` (installed, currently light use), `@phosphor-icons/react` for icons
- Web Audio API for playback + spectrum analyzer

## Asset pipeline (important)

`assets/` holds original masters (WAV, HEIC, big MP4). It is **gitignored**;
Google Drive is the long-term archive. The site only serves compressed
derivatives from `public/`, generated by `scripts/process-assets.sh` using
macOS built-ins (afconvert, sips) + ffmpeg (brew) for large video.

Conversion rules:
- Audio: WAV → AAC m4a 192k (`afconvert -f m4af -d aac -b 192000`); mp3/m4a copied as-is
- Images: HEIC/large JPEG → JPEG max 1600px (`sips -s format jpeg --resampleHeightWidthMax 1600`)
- Video ≤ ~15MB: copy as-is. Larger: `ffmpeg -c:v libx264 -crf 26 -vf "scale='min(1280,iw)':-2" -c:a aac -b:a 128k -movflags +faststart`
- Keep `public/` filenames URL-safe: no spaces or parens; kebab-case or CamelCase

## Playbooks: adding new media

### New song
1. Drop master in `assets/playlist/`
2. Convert (or add a line to `process-assets.sh` and run it):
   `afconvert -f m4af -d aac -b 192000 "assets/playlist/NAME.wav" "public/audio/name.m4a"`
3. Get duration: `afinfo public/audio/name.m4a | grep duration` → format as m:ss
4. Add an entry to `app/data/tracks.ts` (array order = playlist order).
   The playlist UI lives inside PlayerDeck behind the PL toggle
   (`playlistOpen` state in PlayerProvider); there is no separate playlist window.

### New brain scan folder / frames
1. Put numbered PNGs in `assets/brain/brainN/` (named `image_<num>.png`)
2. Run `node scripts/generate-brain-data.mjs` - it re-copies all folders to
   `public/brain/` and regenerates `app/data/brains.ts` (do not edit that file
   by hand). The brain.exe window auto-adds a column per folder.
3. Playback speed is per folder, set in `Hero.tsx`:
   `<BrainLoops fps={{ brain1: 4, brain2: 24, brain3: 12 }} />` (default 8 for
   unlisted folders). Loops run independently. Frames are letterboxed into
   square black viewports, so mixed image dimensions are fine.
4. If `brain2/` (the dense sagittal stack) changed, also run
   `node scripts/build-brain-volume.mjs` to regenerate the 3D volume atlas +
   manifest in `public/brain/volume/` used by brainvol.exe (never edit those
   by hand). Algorithms documented in `scripts/README.md`.

### New band / music tech clip or photo
1. Master into `assets/i_m in a band/` or `assets/music tech/`
2. Convert per rules above into `public/band/` or `public/musictech/`
3. Add `{ kind: "video" | "image", src, alt }` to the `media` array in
   `BandSection.tsx` / `MusicTechSection.tsx`. Captions show the filename
   automatically; videos automatically pause the background music when played.

### New content category (new window/section)
1. Create `app/components/sections/XSection.tsx`: a `<section id="x">` wrapping
   `<WindowFrame title="..." windowId="x" statusFields={[...]}>`
2. Add it to `app/page.tsx`
3. Add a menu item (`href: "#x"`, `windowId: "x"`) in `Hero.tsx` so the nav can
   scroll to it AND raise it (buried-window recovery depends on this)
4. Stagger default position with `md:ml-* / md:mr-*` on the wrapper div; vary
   the offsets so windows feel scattered, not stacked in a column

## Gotchas / conventions

- **98.css buttons render text via `color: #0000` + text-shadow.** Any button
  containing an SVG icon needs the `transport` class (or equivalent unlayered
  override restoring `color`), or the icon is invisible.
- **Cascade layers:** Tailwind utilities live in `@layer`; 98.css is unlayered
  and wins. Overrides of 98.css must be unlayered CSS in `globals.css`
  (see `button.transport`, `button.lcd-row`).
- **WindowFrame collapse** locks the wrapper height so the page never reflows;
  don't remove the wrapper div.
- **Window z-order** goes through `windowRegistry.ts`. Anything that needs to
  reveal a window calls `focusWindow(id)`; new windows should pass `windowId`.
- **Videos pause music** via `MediaGrid`'s `onPlay` → `usePlayer().pause()`,
  and pause other videos. Keep this behavior for any new video surface.
- **Reduced motion:** LCD marquee, spectrum, brain loops, title-bar flash,
  and the brainvol.exe auto-spin all honor `prefers-reduced-motion`. New
  animations must too.
- **brainvol.exe (BrainVolume) needs WebGL2**; it shows a fallback message
  when unavailable. The ~4.4MB volume atlas lazy-loads via
  IntersectionObserver, so it costs nothing until scrolled near. Rendering is
  on-demand (only continuous while auto-spinning), and the default camera
  pose lives in `brainVolumeRenderer.ts` (`theta/phi/dist` + `resetView`).
- Theme is locked: light Win98 silver on teal; dark surfaces only for LCD-style
  displays (`.bezel-lcd`). One accent: `--amber` (current track highlight).
- No em-dashes in visible copy. Body text is 11px MS Sans (98.css default).
